    เดินจงกรมและนั่งสมาธิ

    การเดินจงกรมคือการเดินกลับไปกลับมาในทางสั้นๆ อย่างช้าๆ รู้สึกตัวทุกย่างก้าว การนั่งสมาธิคือการนั่งนิ่ง ตามดูลมหายใจหรืออารมณ์กรรมฐานที่ฝึก ผู้ปฏิบัติมักสลับเดินกับนั่ง เพื่อให้กายไม่ล้าและใจตื่นตัว

    ในจังกมสูตร พระพุทธเจ้าตรัสอานิสงส์ของการเดินจงกรมไว้ ๕ ประการ คืออดทนต่อการเดินทางไกล อดทนต่อการบำเพ็ญเพียร มีโรคน้อย อาหารย่อยดี และสมาธิที่ได้จากการเดินจงกรมตั้งอยู่ได้นาน
