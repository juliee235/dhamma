ส่วนที่ 1 · เตรียมข้อมูล

จากหน้ากระดาษ สู่กราฟที่รู้ว่าแต่ละข้ออยู่ตรงไหน

  • พระสูตร แบ่งตามหัวเรื่อง เช่น ๑. มูลปริยายสูตร, โอฆตรณสูตรที่ ๑, มงคลสูตรในขุททกปาฐะ
  • พระวินัย แบ่งเป็นกัณฑ์ › สิกขาบท (ปฐมปาราชิกสิกขาบท) และขันธกะ › กถา

ส่วนที่ 2 · ตอบคำถาม

ค้นก่อน อ่านจริง แล้วตรวจทุกอ้างอิงด้วยโปรแกรม

  1. Prefetch: ระบบค้นคำถามและแนบตัวบท 5 ข้อแรกให้ agent ก่อนเลย คำถามง่ายจึงตอบได้ในรอบเดียว (ราว 14–30 วินาที)
  2. Agent: ถ้ายังไม่พอ agent ค้นเพิ่มด้วยคำอื่น หาว่าเรื่องอยู่สูตรไหน ดูโครงสร้างหมวด หรืออ่านข้อเต็ม
  3. ร่างคำตอบ: ภาษาง่าย เรียงตามประเด็น และใส่อ้างอิงท้ายข้อ
  4. Verifier: ดึงทุกอ้างอิงจากคำตอบ ไปค้นในฐานข้อมูล แล้วให้สถานะ รวมถึงเช็กว่าคำพูดในเครื่องหมาย “…” ตรงกับตัวบทจริง
  5. Grounding: อ้างอิงที่ยังไม่ใช่สีเขียว หรือคำพูดที่ไม่ตรงตัวบท ระบบเปิดตัวบทจริงให้ AI แก้คำตอบอีกรอบ ที่ยังยืนยันไม่ได้จะถูกตัดออกพร้อมบรรทัดนั้น ผู้ใช้จึงเห็นเฉพาะสีเขียว

สถานะภายในของ verifier (สีอื่นใช้ตัดสินว่าต้องแก้อะไร ไม่แสดงต่อผู้ใช้แล้ว):

อ่านตัวบทแล้วมีอยู่จริง และ agent เปิดอ่านเต็มข้อระหว่างตอบ
อ้างทั้งหมวดอ้างเป็นช่วงที่ตรงกับหมวดในโครงสร้าง เช่น ข้อ 274–287
